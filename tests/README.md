# tests — 测试与审计配套

代码审计的自动化支撑：关键变换必须有"对错判断"，不靠肉眼。

## 测试优先级

| 对象 | 测什么 | 为什么 |
|---|---|---|
| `tiling.py` 分块+融合 | 分块→融合往返后与原图的误差边界 | 接缝伪影是赛题扣分点 |
| 后处理（低频回填/λ混合/色彩对齐） | 关闭时输出恒等；开启时低频统计符合预期 | 提分核心，出错直接毁分数 |
| 提交校验 `validate.py` | 构造错误样本（错名/错尺寸/缺文件）必须被拦截 | 资格红线，零容忍 |
| 指标实现 | 与参考库/公认实现对拍（如 PSNR 容差 <1e-3） | 所有结论的地基 |
| EXIF/IO | 带旋转元数据的图进出尺寸一致 | 手机 4K 图的隐性陷阱 |

## 约定

- 修复缺陷必须连同回归测试一起提交（同 milestone commit）
- CPU 测试不依赖 GPU；远程全量跑：`pytest tests/ -v -m "not remote"`，
  集成冒烟：`pytest tests/test_smoke_diffbir.py -v -m remote`
- 本机无 pytest 时可用最小运行器：`python tests/run_all.py`
