# src/postprocess — 后处理对齐（提分关键）

扩散输出 → 可提交结果之间的最后一公里。评分权重未公布，本层实现"保真 ↔ 生成"连续可调，是应对官方指标不确定性的核心手段。

## 规划模块

- `lowfreq_backfill.py` — 低频回填：将输入图的色彩/亮度低频分量回填输出，压住色调漂移（利好 PSNR/SSIM）
- `lambda_blend.py` — λ 混合：`final = λ·生成增强 + (1-λ)·保真复原`，λ 进配置，在 val 上扫描定值
- `color_align.py` — 色彩对齐：均值/方差或多尺度统计对齐
- `face_branch.py` — 人脸分支：检测 → 专用增强 → 高保真融合回图（test 含小人脸场景，val 无样例，必须兜底）
- `consistency_check.py` — 输出-输入一致性抽查工具（尺寸、内容、色调漂移量报警）

## 约定

- 本层所有操作必须**可关闭、可调参**，关闭后管线退化为纯 enhance 输出
- 任何后处理不得改变输出分辨率
