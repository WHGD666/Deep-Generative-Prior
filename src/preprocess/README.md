# src/preprocess — 预处理

在进入扩散模型前**净化输入**：验证集观察到 case1 存在重彩色噪点、case2/case5 存在模糊。噪声若不先抑制，会被生成模型当作"细节"放大成幻觉纹理。

## 规划模块

- `denoise.py` — 轻量去噪（传统或小型网络，非赛题核心生成步骤，不承担 Diffusion 架构合规性——合规由 enhance 层承担）
- `deblur.py` — 视需要的轻度去模糊（待 baseline 后评估是否保留）
- `tiling.py` — 4K 图分块（含重叠区规划、边缘羽化权重），供 enhance 层使用；也可放 enhance 层，归属随实现定

## 约定

- 预处理强度是**可调参数**，进入配置文件；每档强度对应独立实验记录
- 输出必须是确定性的（同输入同种子同输出），便于复现
