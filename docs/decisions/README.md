# docs/decisions — 技术决策记录（ADR）

记录项目中**重要且不易回退**的技术决策，避免"当时为什么这么选"失忆，同时沉淀为决赛 PPT 素材。

## 命名与格式

- 文件名：`ADR-<三位序号>-<主题>.md`
- 每条 ADR 包含：状态（提议/已接受/已废弃）、日期、背景、候选方案、决策、理由、影响
- 决策被推翻时**不删除旧 ADR**，新开一条并互相引用，旧条目标记"已废弃（被 ADR-XXX 取代）"
