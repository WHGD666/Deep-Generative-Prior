# configs — 配置中心

一切影响实验结果的可调量（模型超参、预处理强度、λ 混合系数、评测权重）都以配置文件形式存在，**代码不含关键数值的硬编码**。

## 目录结构

- `defaults/` — 管线各层的默认配置（去噪强度、分块尺寸、扩散步数、λ、色彩对齐开关等）
- `experiments/` — 每次正式实验的**配置快照**，文件名 = run_id（如 `20260908_diffbir_baseline_a3f2.yaml`），一经提交 git 不可再改，改参即新开文件

## 约定

- 实验的可复现闭环 = 代码版本（git commit）+ 配置快照 + 数据指纹 + 权重哈希，四者都记入 `experiments/<run_id>.json`
- defaults 变更视为管线升级，须在 EXP_LOG 说明
